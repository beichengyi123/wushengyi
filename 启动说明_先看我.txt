无声有译 · 启动说明（先看我）
========================================================
一、最省事：只双击一个文件
--------------------------------------------------------
  程序本体（就这一个文件，别的都不用碰）：
    桌面 → WuShengYi_GUI 文件夹 → WuShengYi 文件夹 → 无声有译.exe
    完整路径：
    C:\Users\Administrator\Desktop\WuShengYi_GUI\WuShengYi\无声有译.exe

  建议（10 秒搞定，以后直接双击桌面）：
    打开上面的文件夹 → 右键 无声有译.exe → 发送到 → 桌面快捷方式
    以后桌面上就有「无声有译 - 快捷方式」图标。

  它自己会做三件事：
    1. 拉起 Flask 网站后端     127.0.0.1:5000
    2. 拉起 智能体服务         127.0.0.1:8080
    3. 打开摄像头，准备识别

  看软件右上角：
    ● 后端在线     ● 智能体在线      -> 都变绿了就能用
    黄色"启动中"  = 正在起，智能体要 8~15 秒，等一下
    红色"离线"    = 没起来，看第四节


二、网站怎么打开
--------------------------------------------------------
  【推荐】开好软件后，点软件里的「🌐 打开网站」按钮
          浏览器自动弹出，不用记地址、不用复制粘贴。
          按钮在右下角，"提交智能体"下面那一行左边。

  旁边还有「📋 手机地址」按钮：
          点一下就把 http://电脑IP:5000 复制好了，
          手机连同一个 WiFi，粘贴到浏览器就能看大屏。

  地址本身（记一下也不吃亏）：
          电脑：http://127.0.0.1:5000
          手机：http://10.16.197.173:5000   ← 换网络会变，用上面的按钮复制最稳

  注意：网站要靠"后端"这个服务活着。
        双击桌面端软件它就自动起来了，不用另外开。
        右上角没亮绿灯时点「打开网站」会提示你等一下。

  想单独开网页（不开桌面软件）：
        双击  桌面\无声有译-项目\0_一键启动全部.bat
        它会起两个服务 + 自动弹出浏览器。

四、起不来怎么办
--------------------------------------------------------
  1) 先看软件右下角"运行日志"，它会直接写哪一步失败。
  2) 还不行就看日志文件：
       桌面\WuShengYi_GUI\WuShengYi\logs\backend.log
       桌面\WuShengYi_GUI\WuShengYi\logs\agent.log
  3) 端口被占（提示 5000 或 8080 already in use）：
       双击  99_停止全部服务.bat  然后再开软件
  4) 自动启动实在不行，退回手动三步：
       双击  0_一键启动全部.bat
       浏览器打开 http://127.0.0.1:5000
  5) 想关掉自动启动：改
       桌面\WuShengYi_GUI\WuShengYi\config.json
       把 "autostart_services": true 改成 false


五、关闭顺序
--------------------------------------------------------
  关掉软件窗口后，两个服务仍在后台跑（网页还能继续访问，这是故意的）。
  要彻底停：双击  99_停止全部服务.bat
  或者关机重启，什么都不用管。


六、演示当天建议顺序
--------------------------------------------------------
  1. 手机开热点，热点名 1，密码 你的WiFi密码
  2. ESP32 上电（TFT 显示连上 WiFi 后会显示版本号）
  3. 双击桌面的「无声有译」
  4. 等右上角两个绿灯
  5. 浏览器开 http://127.0.0.1:5000
  6. 比手势 -> 出词 -> 提交智能体 -> 发到屏幕
