================ INMP441 麦克风 · 接线与使用说明（v5） ================

一、接线（和已确认的接线表一致）
  INMP441 引脚      ESP32 引脚
  VDD        ->     3.3V          （不许接 5V，会烧）
  GND        ->     GND
  L/R        ->     GND           （接地 = 左声道，代码只收左声道）
  SCK(BCLK)  ->     GPIO14
  WS(LRCLK)  ->     GPIO13
  SD(DOUT)   ->     GPIO26

  与原模拟麦相比：GPIO34 不再使用；GPIO13/14/26 是新占用脚，
  不和 TFT 屏（MOSI=23/SCK=18/CS=15/DC=27/BL=32）冲突。

二、烧录
  1. 固件实际位置（Arduino IDE 打开 .ino 时会自动建同名文件夹，这是正常现象）：
     桌面\无声有译-项目\固件与ESP32\ESP32_INMP441_Voice_v5\ESP32_INMP441_Voice_v5.ino
  2. 本机 Arduino IDE 在 D:\arduino\Arduino IDE\Arduino IDE.exe，ESP32 核心版本 3.3.10（3.x 版）
     —— 代码已用 3.x 自带的 ESP_I2S 库，和老 1.x/2.x 的 driver/i2s.h 写法不同，不要混用。
  3. 需要这三个库（工具 → 管理库 里搜名字安装，装过就跳过）：
     PubSubClient（Nick O'Leary）、TFT_eSPI（Bodmer）、U8g2_for_TFT_eSPI（olikraus）
  4. WiFi 账号密码已按原固件保留（WiFi 名"1"，密码"你的WiFi密码"），不用改
  5. 开发板选 ESP32 Dev Module，选对 COM 口，点上传
  6. 打开串口监视器 115200，复位板子

三、上电自检（串口看两行就够）
  [麦克风] INMP441 I2S 就绪 (BCLK=14 WS=13 SD=26), 自动断句模式
  [麦克风] RMS xx | 底噪 xx | 阈值 xx     <- 每秒打印
  静音时 RMS 应该很小（几十以内）；对着麦克风说话 RMS 应该明显变大（几百以上）。
  如果说话 RMS 纹丝不动 -> 检查 SD 线是否插 GPIO26、L/R 是否接地；
  如果说话 RMS 一直飘很高（几百上千下不来）-> 底噪异常，检查 VDD 是否 3.3V。

四、整机链路（2026-11-15 起音频改走局域网直连，快 3 秒左右）
  INMP441 采集 -> 板内降采样成 8kHz PCM（和老模拟麦格式一模一样）
  -> 响度归一（整句统一放大）
  -> 【主通道】电脑软件启动后会把本机 IP 发到 aiot/pc/info，
     板子收到后音频走 TCP 直连电脑 5001 端口（局域网内几十毫秒）
  -> 【回退】收不到电脑 IP 或连不上时，自动退回公网 MQTT（慢 3 秒但能用）
  -> 电脑端识别 -> voice_api.py 百度短语音（API Key 已在文件里）
  -> 文字回传 MQTT -> TFT 屏幕青色区显示 + 桌面软件"语音通道"卡片显示

  注意：
  · 语音出字靠"无声有译.exe"（或源码 gui_app.py），它开着屏幕才会出字
  · 电脑的 Windows 防火墙需放行 TCP 5001（规则名 WuShengYi-Voice-5001，已加）
  · 电脑换 WiFi/换 IP 后：软件会每 30 秒自动重新通知 IP，板子最多 30 秒内跟上；
    板子重启也会立即拿到最新 IP。无需手动改任何东西。

五、常见问题
  · 识别出来是空/乱字：串口把 MIC_DEBUG 改 0 排查先；电脑端打印会提示
    "安静或只有底噪, 跳过"（说明响度归一后仍偏小，把 INMP_SHIFT 从 16 改成 14 或 12 加增益）。
  · 说话总断不开/说完了不发送：QUIET_CHUNKS=4（0.4 秒停顿即发送），
    觉得太灵敏改 5~6，太迟钝改 2~3。
  · 想改回按键说话：USE_BUTTON 改 1（按键接 GPIO4+GND，或用板载 BOOT 键）。
  · 老固件备份还在：ESP32_Voice_Final.ino（模拟麦 GPIO34 版本），随时可换回。
