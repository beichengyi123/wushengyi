二、接口一览（都挂在原有 5000 端口，没有新服务）
================================================================
  GET  /collect                          采集页面
  GET  /api/collect/labels               标签列表（含手位/待考核/正式数量）
  POST /api/collect/labels               新建标签 {label, hand}
  POST /api/collect/labels/clear         清空该标签的待考核样本（正式库不动）
  GET  /api/collect/samples?label=       待考核样本列表
  POST /api/collect/samples              上传一条样本 {label, frames:[base64...]}
  DELETE /api/collect/samples            删一条 {label, name}
  GET  /api/collect/thumb/<标签>/<图>    样本缩略图
  POST /api/collect/selfcheck            AI 自检（本地模型+手位规则，不联网）
  POST /api/collect/promote              确认入库（待考核 -> sign_data）
  POST /api/collect/retrain              重训本地模型（调原 train_model.py）

三、完整测试流程（照着走一遍就能验收）
================================================================
  0. 双击桌面软件（或 0_一键启动全部.bat），等后端在线。
     用本机浏览器打开 http://127.0.0.1:5000/collect
     （注意：手机用局域网 http 打开会看不到摄像头，浏览器只允许本机/https）
  1. 新增标签：点「+ 新增标签」，输入名字（如 宿舍），
     手位规则选【右手手势】，点创建。
  2. 按手位采集：画面出来后，用右手比动作，按「采集一条」（或空格），
     保持约 1.5 秒。存进待考核库；手位不对会被当场拒绝并提示。
  3. 多采几条：5 条起步，换角度/换光照/换远近，别用同一次动作反复录。
  4. AI 自检：点「开始 AI 自检考核」。
     · 合格 -> 绿色结论 + 「确认入库」按钮
     · 不合格 -> 给出原因（被认成哪个词 / 手位不对）+ 两条推荐方向：
       A 继续补样本再自检；B 清空待考核重采
  5. 入库：点「确认入库」，样本移入 sign_data/<标签>/，手位规则一起转正。
     再点「重新训练本地模型」（就是原来的 train_model.py），
     完成后重启识别程序，新词即可参与识别。
  6. 正式识别验证：识别端同样启用了人脸误检过滤 + 手位校验——
     脸凑近摄像头不会再蹦出假词；登记了"右手"的词用左手比不出词。

四、防误检规则的参数（都在 sign_guard.py 顶部，要调就改这里）
================================================================
  MIN_HAND_SCORE = 0.75   手部置信下限
  FACE_INSIDE_RATIO = 0.5 手关键点落进人脸框的比例超过它就丢弃
  FACE_BOX_PAD = 0.12     人脸框外扩系数
  FACE_EVERY = 2          每两帧做一次人脸检测（省算力）

五、AI 自检的判定逻辑（不许用户填阈值，全部系统内部决定）
================================================================
  1) 样本数 < 5        -> 直接判"样本太少"，给补采建议
  2) 每条样本双重校验：
     ① 图像模型：本地 sign_model.npz 的 kNN 推理，识别结果必须是本标签
        （老标签）；新标签做"和已有词撞车"的冲突检查
     ② 手位规则：采集时记录的真实左右手帧数，必须匹配标签登记的手位
  3) 通过率 >= 60% 且手位符合率 >= 80% -> 合格
  全程只用本地文件，不调用任何外部 API、不依赖外网。
