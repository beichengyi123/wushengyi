================================================================
无声有译 · 局域网 Web 中控 —— 启动步骤 / 参数修改 / 排错
================================================================
本目录是"Web 中控"部分。1.py 和识别相关代码一行没动，
数据和屏幕文字全部由 bridge_mqtt.py 旁听得来。

----------------------------------------------------------------
一、目录结构
----------------------------------------------------------------
web\
  app.py               后端(Flask)：记录、看板数据、终端控制、CSV、词库
  bridge_mqtt.py       桥接：盯 sign_log.txt + 订阅 MQTT -> 发给后端
  gen_gesture_images.py 词库配图生成器（跑一次即可，重录样本后再跑一次）
  words_info.json      词释义（想改释义文字就编辑这个文件）
  templates\           三个网页（看板 / 词库 / 历史）
  static\              样式 + JS + 配图（static\gestures\ 是骨架图）
  data\                自动生成：records.db 数据库 + config.json 配置
  esp32\ESP32_WebCtrl\  新 ESP32 固件（HTTP 轮询版）

----------------------------------------------------------------
二、启动步骤（顺序不能乱）
----------------------------------------------------------------
【第1步】开识别端（老流程，没变）
  D:/python/python.exe 1.py
  → 摄像头窗口出来、MQTT 已连接 即可

【第2步】开后端（新窗口）
  cd 桌面\无声有译-项目\web
  D:/python/python.exe app.py
  → 看到 "Running on http://0.0.0.0:5000" 即可

【第3步】开桥接（新窗口）
  cd 桌面\无声有译-项目\web
  D:/python/python.exe bridge_mqtt.py
  → 看到 "MQTT 已连接 + 已订阅" 即可
  （顺序提示：先比划一个词再开桥接也行，日志从末尾开始跟，不会重放旧记录）

【第4步】ESP32 上电
  固件在 web\esp32\ESP32_WebCtrl\，Arduino 烧录（详见第六节）

【第5步】浏览器打开中控网站
  本机：     http://127.0.0.1:5000
  手机/同网： http://192.168.5.115:5000   ← 电脑IP变了要跟着改

验证通了没有：在 1.py 里比一个词 →
  桥接窗口出现 [手语] 词 分数…、[屏幕-word] …
  网页看板"通道A"出现该词和置信度条 → 全链路 OK

三、参数修改说明（都在文件顶部，注释写了怎么改）
----------------------------------------------------------------
【web/bridge_mqtt.py】
  MQTT_BROKER / TOPIC_*     必须和 1.py 顶部一致（1.py 换 broker 这边跟着换）
  FLASK_URL                 后端地址，一般不用动
  FRESH_SEC                 日志分数和屏幕消息的配对窗口，默认 3 秒

【web/app.py】
  PORT = 5000               网站端口；改了 ESP32 固件里 SERVER_PORT 也要改
  DEFAULT_CONF              首次启动的默认值：阈值 0.50 / 自动模式 / 不锁屏
                            之后的修改在网页上点按钮就会存到 data\config.json

【web/esp32/ESP32_WebCtrl.ino】（文件开头"现场要改的参数"）
  WIFI_SSID / PASSWORD      你的 WiFi
  SERVER_HOST               跑 Flask 的电脑 IP（cmd 输 ipconfig 看 IPv4 地址）
  MIC_GAIN                  音量增益：1.py 控制台总显示"安静"→调大(6/8)；
                            没说话也一直识别→调小(2/1)。看 1.py 打印的"人声音量"调，
                            正常说话 500~900 最理想
  RECORD_SECONDS            每轮录音秒数，默认 2（屏幕刷新间隔=这个值）

【网页上可改（不用动代码）】
  置信阈值：看板页输入 0~1 保存，低于它的词不推 TFT
  推送模式：自动（识别就上屏）/ 单句（只接受手动发送）
  锁屏/清屏/手动下发文字

----------------------------------------------------------------
四、ESP32 烧录要点
----------------------------------------------------------------
1. 库：TFT_eSPI、U8g2_for_TFT_eSPI、PubSubClient（必须 2.8 以上，
   老版本没有 setBufferSize，编译会报错；库管理器里更新即可）
2. TFT 引脚沿用原 User_Setup.h（本固件没重复配引脚）
3. 开发板选 ESP32 Dev Module
4. 烧完看串口(115200)：连上 WiFi 会打印 IP，"MQTT 已连接"= 音频路 OK

----------------------------------------------------------------
五、排错提示（按症状查）
----------------------------------------------------------------
【网页打不开】
  - app.py 是否真的在跑（窗口有没有红字报错）
  - 手机访问不通：电脑和手机是否同一 WiFi；Windows 防火墙第一次会弹
    "允许访问"，点了允许；或手动放行 5000 端口
  - 电脑 IP 变了（换网络就会变）：重新 ipconfig，改固件 SERVER_HOST 重烧

【看板一直没数据】
  - 顺序：1.py 在跑吗 → bridge_mqtt.py 开了吗 → 桥接窗口有没有红字
  - "发给后端失败"：app.py 没开或端口被占
  - 比划了词但没反应：sign_log.txt 有没有新行（1.py 每确认一个词记一行）

【ESP32 屏幕不出字】
  - 固件里 SERVER_HOST 对不对（对电脑 ipconfig 核对）
  - 电脑防火墙放行 5000
  - 屏幕显示"屏幕已锁定"→ 网页上点解锁
  - 单句模式下识别结果不上屏是正常的，只有手动发送才上

【ESP32 说不了话（1.py 收不到音频）】
  - 串口看 "音频发送失败" → MQTT 没连上，看 WiFi
  - 1.py 显示"安静或只有底噪" → 调大 MIC_GAIN（固件顶部，改完重新烧）
  - 没说话也一直识别 → 调小 MIC_GAIN

【置信度不显示 / 一直拦截】
  - 阈值默认 0.50，分数低于它就拦截。看板页把阈值调到 0.3 试试
  - 历史记录页能看到每条词的分数，据此定阈值更科学

【CSV 打开乱码】
  不会乱码（已带 BOM）。若用 WPS/Excel 打开仍异常，用"数据→导入"选 UTF-8

【词库页没配图】
  跑一次：D:/python/python.exe web/gen_gesture_images.py
  （重新采集/重录样本后再跑一次就会更新）

六、功能对照（只做了清单里的，没有额外功能）
----------------------------------------------------------------
 1 三端联动      → 看板页实时显示手语/语音，TFT 同步（HTTP 轮询）；
                   手动下发文字 / 锁屏 / 自动·单句模式 都在看板右侧
 2 置信度+快照   → 手语词存分数/距离/门槛/时间戳（来自 sign_log.txt）；
                   语音存文本/时间戳；看板画置信度条，低于阈值不推 TFT
                   ⚠ 抓拍图片：1.py 不存图，见 README 末尾"已知缺口"
 3 词库页        → 手部骨架配图（样本自动生成）+ 释义 + 查看样本
 4 历史记录      → 手语/语音分开展示，一键导出 CSV（Excel 直开不乱码）

----------------------------------------------------------------
七、已知缺口（实现冲突，按约定反馈不擅改）
----------------------------------------------------------------
1. 抓拍图片存不了：1.py 只发文字，不存摄像头帧。要补上需要在
   1.py 的 _emit_word() 里加约 6 行存图代码——你点头我才动。
   在补上之前，记录里的"图片"字段留空，其余功能不受影响。
2. 公网 broker：1.py 连的是 broker.hivemq.com（公网），与
   "全程内网离线"冲突。不改 1.py 就只能保留；若接受改 1 行
   （MQTT_BROKER 指向本机局域网 IP + 装 mosquitto），告诉我。
3. 语音原文：1.py 上屏前把语音文字去了标点截断到 12 字，桥接拿到
   的是处理后的文本（原文只在 1.py 控制台打印）。历史记录里
   存的就是这个版本。

八、升级后的完整启动顺序（2026-11-07 起）
================================================================
  1) 网站后端        双击 web\1_启动后端.bat          -> 5000
  2) 智能体服务      双击 agent\start_agent.bat       -> 8080
  3) 桌面软件        双击 gui\dist\无声有译\无声有译.exe
  4) ESP32 上电      自动轮询 5000

  说明:
   · 第 1 步必须最先开, 智能体处理完要回调它落库
   · 第 3 步的桌面软件可以替代 1.py: 识别逻辑一样, 多了界面和抓拍
   · 1.py 仍然可用(命令行版), 两者不要同时开摄像头

  本次新增的两个接口(详见 agent\接口文档.txt):
   · POST /api/snapshot      桌面软件上传抓拍图 -> static/snapshots/
   · POST /api/agent_record  智能体回调落库(沿用 records 原表)
  数据库只加了一个可空列 tag(陈述/询问/问候), 老数据与老代码不受影响。
