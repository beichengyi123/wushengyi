🧩系统组成

四个角色，各干各的活，数据走 MQTT 和 HTTP 汇到一起
🤟 识别端（桌面软件 / 1.py）➜ 📡 数据桥 bridge_mqtt.py➜ 🌐 本网站（:5000）➜ 🖥️ ESP32 TFT 屏
  • 识别端：打开摄像头做手语识别（MediaPipe 21 关键点 + kNN 分类），支持语音转文字，也能直接把结果润色成通顺句子。
  • 本网站：中控台。看实时识别结果、管阈值、控 TFT 屏幕、查历史、采集新样本，全在浏览器里完成。
  • ESP32 TFT：小屏幕终端，每 1~2 秒向网站轮询一次，有新内容就重画。

🚀启动顺序

顺序有讲究，反了会互相连不上
  1. 双击桌面的 手语翻译.exe（识别端，开摄像头）。
  2. 开 web 后端：命令行运行 python web\app.py（桌面软件会自动拉起，一般不用手动）。浏览器访问 http://127.0.0.1:5000。
  3. 开数据桥：python web\bridge_mqtt.py（识别结果 → 网站 → TFT 靠它转发）。
  4. ESP32 上电（已烧录固件的情况下），屏幕右上角小点变绿即连上。
💡嫌麻烦就用项目根目录的 0_一键启动全部.bat，一条命令全拉起；结束用 99_停止全部服务.bat。

📊看板页（首页）

实时盯着两条通道：手语在左（黄字），语音在右（蓝字）
  • 通道 A · 手语识别：比划时句子逐词出现在大字区，下方是置信度进度条。低于阈值的词会标红并被拦截——只在网页显示，不上 TFT 屏。
  • 通道 B · 语音转文字：对麦克风说话，转写结果直接显示。
  • 置信阈值：默认 0.50。想更严格就调高（比如 0.60），误识别会变少，但正确的词也可能被拦。改完点"保存阈值"。
  • 推送模式：自动推送 = 识别到就上 TFT；单句推送 = TFT 只接受你在"手动下发"框里输入的内容，适合演示时精确控屏。
  • 锁屏 / 清屏：锁屏后任何内容都上不了 TFT；清屏把两行内容清空。

📚手语词库页

当前模型认识的所有词都在这，点卡片看详情
  • 每个词显示样本数量和标准手势图、释义。
  • 点开卡片可看该词的全部采样照片，用来核对手势比得标不标准。
  • 样本太少（比如只有几条）的词识别会不稳，建议去"样本采集"页补录。

🗂️历史记录页

  • 分手语、语音两个标签页，手语记录带置信度分数、单/双手、当时拼到的句子。
  • 被阈值拦截的记录标红显示"拦截"，方便回溯"为什么没上屏"。
  • 每条手语记录带抓拍图，点缩略图看大图。
  • 右上角可导出 CSV（Excel 直接打开不乱码），交作业、写报告直接用。

🎥样本采集页

教模型学新手势的唯一入口——录样本 → AI 自检 → 入库 → 重训
  1. 新建标签：输入词（如"谢谢"），选好手位规则（单手右手 / 单手左手 / 双手）。手位不符的帧会被自动丢弃，防误录。
  2. 录制：点采集后先 3-2-1 倒计时，然后把你的手举进画面，检测到才自动开录——动作没做出来不会白录。接着完整做一遍动作，做完停 0.6 秒（或手放下）自动结束，最长录 3 秒，中途点按钮可取消。连贯动作也能完整录进去。
  3. AI 自检：点"开始自检"，系统用当前模型反测你的新样本。不用填任何阈值——通过率 ≥60% 且手位正确率 ≥80% 才算合格；不通过会给 A（直接重录）/ B（先入库再重训）两条建议。
  4. 入库 + 重训：样本合格后点"入库"，再点"重新训练"。训练完成后新词立刻生效，识别端不用重启。
⚠️必须用 http://127.0.0.1:5000 或 http://localhost:5000 打开采集页，浏览器安全策略只允许本机地址开摄像头；用局域网 IP 打开会黑屏（页面会提示并给一键跳转按钮）。
💡打开采集页后，桌面软件的摄像头会自动让位（8 秒内检测到你在采集就暂停它的摄像头，画面变成黄字提示），关掉采集页标签页后自动恢复，不用手动开关。
💡采集时手机也能看：别人用局域网地址（或扫二维码）打开采集页会进入围观模式，实时同步你电脑端的画面、骨架和录制进度，只看不操作，适合演示。

🔧常见问题

采集页摄像头黑屏 / 打不开？

三种情况：地址不对（用 127.0.0.1 打开）、浏览器没给权限（地址栏左边锁图标里允许摄像头）、摄像头被别的软件占了（关掉其它占用摄像头的程序再刷新）。

桌面软件画面定格不动，提示摄像头被占用？

这是正常让位：你在采集页录样本时软件主动停了摄像头。关掉采集页（或切走标签页 8 秒以上）会自动恢复。

识别出来但 TFT 屏不显示？

按顺序查：① 看板里该词是不是被标红"拦截"（低于阈值）；② 是不是开了"单句推送"模式；③ 是不是点了"锁屏"；④ ESP32 和本机是否在同一个局域网、bridge_mqtt.py 是否在跑。

某个词总是识别错？

去采集页给这个词补录几条样本（换角度、换距离），自检通过后入库重训。样本越多越稳，同一个词建议保持 15 条以上、覆盖不同距离。

历史页导出的 CSV 用 Excel 打开是乱码？

不会乱——导出用的是 utf-8-sig 编码，Excel 双击直接打开。如果你用了 WPS 老版本还乱码，在 WPS 里选"文件 → 打开"并手动指定 UTF-8 编码。
