======================================================================
 无声有译 · 电脑端 GUI 桌面软件 使用说明
======================================================================

一、这是什么
----------------------------------------------------------------------
  把原来的命令行程序 1.py 包装成窗口软件：打开就自动开摄像头，
  画面实时预览，手语识别出词后自动拼成一句，可一键发给 ESP32 屏幕，
  也可以提交给后端智能体润色成通顺中文。

  识别逻辑完全复用 1.py（模型、归一化、kNN、防抖状态机、词组合并），
  一行没改；本软件只负责"界面 + 两条输出分支 + 抓拍存档"。

二、文件说明
----------------------------------------------------------------------
  gui_app.py      主程序（开发运行用：D:\python\python.exe gui_app.py）
  build_exe.py    打包脚本（生成免 Python 环境的 exe）
  config.json     配置（第一次运行自动生成，可直接用记事本改）
  snapshots\      本地抓拍图（断网时也不丢，图上同时会上传网站）

三、配置项（config.json）
----------------------------------------------------------------------
  {
    "backend": "http://127.0.0.1:5000",                  // Flask 网站
    "agent": "http://127.0.0.1:8080/api/agent/compose",   // 智能体接口
    "camera": 0,                                          // 摄像头编号
    "push_polished_to_tft": true,                         // 润色结果是否也上屏
    "snapshot": true                                      // 出词时自动抓拍
  }

  · 网站和智能体装在同一台电脑: 保持 127.0.0.1 就行
  · 网站装在另一台电脑: 把 backend 改成那台机的局域网 IP
  · 笔记本自带摄像头是 0，插 USB 摄像头一般改成 1

四、界面怎么用
----------------------------------------------------------------------
  左边   摄像头画面（21 点骨架 + 镜像显示）
  右上   当前手势 / 距离·门槛 / 帧率   —— 判断识别是否稳定看这里
  右中   识别出的词汇序列（比手势时一个字一个字往上拼）
  右下   智能体润色结果（含标签：陈述/询问/问候）

  按钮:
  ▶ 发送到屏幕      把当前这句发给后端 -> ESP32 两秒内显示（等同 1.py 按回车）
  ↩ 撤销一个词      点错了退回上一个词；本句已发送时再点=恢复上一句
  ✕ 清空            清掉当前词，屏也一起清
  📷 抓拍存档       手动抓一张存到网站（不带识别记录，单纯留证）
  🤖 提交智能体     把词序列交给后端润色，结果显示在下面，并可自动上屏

五、打包成 exe（免 Python 环境）
----------------------------------------------------------------------
  1) 确认已装 PyInstaller（本机已装 6.22.3）
  2) 在 gui 目录执行：D:\python\python.exe build_exe.py
  3) 产物：gui\dist\无声有译\无声有译.exe
     同目录还会自动放好 1.py / sign_model.npz / sentence_api.py / voice_api.py
  4) 把整个 "无声有译" 文件夹拷到任何 Windows 电脑，双击 exe 即可运行

  为什么要目录版而不是单 exe:
    mediapipe + opencv 体积大（约 500MB），单文件版每次启动都要解压，
    演示现场要等十几秒；目录版双击秒开。要单文件把 build_exe.py 里
    ONEFILE 改成 True 重新打包即可。

六、常见问题
----------------------------------------------------------------------
  打开就提示"打不开摄像头"
      摄像头被其它程序占用（微信/腾讯会议/浏览器标签）先关掉；
      或在 config.json 把 camera 改成 1 试试

  识别很慢 / 帧率只有 5~10
      笔记本性能或光线问题；把摄像头分辨率降低、或关掉其它占 CPU 的程序
      帧率低时防抖参数会自动按帧率缩放，不会吞词

  右上角显示"后端离线"
      Flask 网站没开：双击 web\1_启动后端.bat。此时识别照常，只是不上屏

  右上角显示"智能体离线"
      智能体服务没开：双击 agent\start_agent.bat

  能识别但屏幕不动
      ESP32 没上电/没连同一热点；或板子固件里的 SERVER_HOST 不是当前电脑 IP

  抓拍图在网站上看不到
      网站没开时只存本地 snapshots\；开了网站会自动上传到 web\static\snapshots\

七、启动顺序（演示建议）
----------------------------------------------------------------------
  1) web\1_启动后端.bat        网站 5000
  2) agent\start_agent.bat     智能体 8080
  3) 无声有译.exe              桌面软件
  4) ESP32 上电                轮询 5000
